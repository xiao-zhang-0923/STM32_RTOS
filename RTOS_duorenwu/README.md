## 2 图片怎么插

博客里统一用这种占位：

```
> 📷 **图 1-1**：CubeMX 选择 STM32F103C8Tx
> （请插入截图）
```

在 Typora / CSDN 编辑器里，把占位替换成你自己的截图即可。建议按编号顺序截图，方便对照。

已附带的真实图片（可直接上传）：

| 图片 | 用在哪 |
|------|--------|
| `images/i2c_init_sequence.png` | 任务二 7.3 初始化时序 |
| `images/i2c_measure_sequence.png` | 任务二 7.4 测量时序 |
| `images/i2c_bit_timing.png` | 任务二 7.5 位级时序 |

> 这三张是按程序实际发送字节绘制的**时序示意图**，不是示波器截图。
> 如果你用示波器/Keil 逻辑分析仪抓到了真实波形，建议替换成自己的截图，并在图注里写明“实测”。

## 3 发布到 CSDN 的小提示

1. 先在 Typora 里把图片占位替换成本地图片（Typora 会自动复制到 `.assets`）；
2. 复制到 CSDN 编辑器时，图片会自动上传；
3. CSDN 支持 `[Toc]` 自动生成目录，粘贴后保留即可；
4. 代码块语言选 `c`、`asm`、`bash`，表格用 Markdown 表格；
5. 标签建议：
   - 任务一：`#stm32` `#嵌入式` `#rtos` `#ucosiii` `#hal`
   - 任务二：`#stm32` `#i2c` `#aht20` `#传感器` `#rtos`
6. 发布前把“笔者”的实验数据（温湿度数值、示波器截图）换成你自己实测的。
